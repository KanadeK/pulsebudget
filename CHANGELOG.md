# Changelog

All notable changes are documented here. The format follows Keep a Changelog, and the project uses
Semantic Versioning.

## [0.1.0] - 2026-08-23

### Added

- Strict, unit-aware CSV and JSON budget inputs.
- Time-aware charge, average, peak, p95, pulse, and battery-runtime analysis.
- Normalized baseline/candidate comparison with exact idle, pulse-amplitude, and pulse-activity
  attribution.
- Explicit budget evidence and stable `0`/`1`/`2` CLI exit codes.
- Deterministic JSON, Markdown, and SVG reports.
- Real embedded-style example traces, CI, wheel/sdist, standalone `.pyz`, and release checks.
